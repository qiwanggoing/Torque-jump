## 结论（只在训练曲线能支持的范围内）

1. **yaw 惩罚没有掐死发现。** squat_qualified_rate 收敛到 0.987/0.987，与无罚 run
   的 0.965/0.950 同级甚至略高。历史上 `99edf7a` 记录的“未 gate 的 yaw 罚让
   flight=0.000”没有复现 —— 说明现在这个 latch-gated 版本是 discovery-safe 的。
2. **早期略慢。** yaw03_s1 在 iter 2000/4000 的 successful_jump 为 0.000，
   yaw03_s2 在 iter 2000 的 squat 只有 0.608（无罚 s2 是 0.983），4000 后追平。
   代价存在但是暂时的。
3. **中期掉坡不是 yaw 罚造成的。** 8000→10000 的下滑在**无罚的 s2 里同样出现**
   （0.564→0.263），yaw03_s2 是 0.504→0.236，形状一致。这是种子/课程现象，
   不能归因到惩罚项。
4. **同代 hit_rate 上，yaw03_s1 落在两个无罚种子之间**（@11000：0.478 vs
   0.652 / 0.279）。n=1 对 n=2，且训练曲线不能排名 → **不构成“变差”的证据，
   也不构成“没变差”的证据**。

## 还缺的（必须做，否则 yaw 这刀无法验收）

- `rew_base_yaw_rate` 的时间序列（确认惩罚项真的在降，而不是权重太小被无视）。
- 确定性 eval + **起跳瞬间 ω_z** 测量。这是 yaw 洞的直接指标，曲线里根本没有。
  验收线：起跳 |ω_z| < 0.5 rad/s、飞行段转角 < 10°，且 squat gate 与落点精度不掉。
  参照：14700 转 4.8°（起跳 ω_z 0.02）；两个 20k 无罚 run 转 ~57°（起跳 ω_z 2.88，140×）。
